# Deciding if a rule needs a Qualifications line

**When:** reviewing completeness of `Qualifications:` lines in the rights-model rules.

## Why
Every base rule must name every rule that bounds it, so the question returns each review.

## What to do
Quote the base rule whole and ask: is the reader left confident in something false? ER-5 without ER-9, ER-11 without ER-17: yes, line owed. ER-6 already says "direct", so ER-7 owes none; do not re-raise it. Section prose keeps its inline clauses by PO ruling; do not flag it.

## What not to do
Do not use "does X narrow Y's subject": it catches every adjacent rule.
