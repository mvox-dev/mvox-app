# Writing a proposal the PO can rule on

**When:** sending recommendations up for a ruling.

## Why
On #255 all four recommendations were ruled in one pass.

## What to do
One recommendation per question, each grounded in a read done that pass, each with the alternative stated fairly enough to be ruled for. For every "don't do X", name what X would break at a file:line.

## What not to do
Do not argue by framing or preference.
