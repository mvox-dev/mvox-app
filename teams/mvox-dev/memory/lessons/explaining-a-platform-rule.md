# Explaining a platform rule

**When:** about to describe or "improve" a platform mechanic in a doc, spec or PR.

## Why

The _inheritrights rule is one sentence in the Entu docs. A long explanation built from source code spread into specs and was wrong; corrections made by reasoning were wrong too. Confident, detailed and wrong is worse than a plain quote.

## What to do

Open the primary human-readable docs (for Entu, the entu/www repo) and quote them. If a spec already states the rule plainly, leave it. When unsure, say so and read the source of truth.

## What not to do

Do not paraphrase from memory, and do not work rules out from platform source code.
