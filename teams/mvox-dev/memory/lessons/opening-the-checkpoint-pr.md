# Opening the checkpoint PR

**When:** the `chore/...-checkpoint` branch is committed and the PR is next.

## Why

Mihkel reviews the diff first, especially the [NEXT SESSION] seed and new scratchpad lines.

## What to do

Pause after the commit, tell Mihkel the branch is ready, open the PR when he has looked.

## What not to do

Do not open and merge the checkpoint PR in one go.
