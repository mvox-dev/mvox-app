# Citing Entu rights docs

**When:** quoting an entu-www table row or reading a rights sweep.

## Why
The `_owner`, `_editor` row in `api/properties/index.md` sits under "Deleting a Property / Restrictions": it is about deletion, not read visibility. It caught two readers on #468.

## What to do
Print the enclosing `##`/`###` heading with any docs table row before citing it. In rights sweeps, "absent" can mean unreadable: they read the private bucket.

## What not to do
Do not cite a table row without its heading.
