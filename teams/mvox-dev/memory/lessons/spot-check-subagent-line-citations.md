# Spot-check subagent line citations

**When:** a subagent cites a line number in a large or single-line JSON file.

## Why

A haiku subagent cited line 1485 of a file about 250 lines long; the claim was right, the citation invented.

## What to do

- Open the file and confirm the cited line before relaying it.

## What not to do

- Do not pass on line numbers into JSON unchecked.
