# Quote the platform docs before theorizing

**When:** writing a doc or spec that states how Entu behaves, or about to probe or ask the PO about a platform rule.

## Why

Reasoning from memory or from entu/api source produced several confident, wrong corrections; one plain sentence in entu/www already held the rule. A one-line PO question once grew into six probes and contradictory authorizations.

## What to do

- Open entu/www (urls/entu-www-repo) and quote the sentence.
- Probe only what the docs do not cover.
- Act on an explicit PO directive without re-asking.

## What not to do

- Do not paraphrase a platform rule from memory.
- Do not dress a one-line rule up as a theory.
- Do not ask the PO what the schema or docs already answer.
