# Writing an implementation plan

**When:** turning a spec into a plan (for example with superpowers:writing-plans).

## Why

A plan's content depends on who runs it: a team plan names Tallis, Byrd, Comenius, Bentham,
Josquin and Perotin per task; a subagent plan does not. Asking "which mode?" after writing it is
incoherent; the plan already chose.

## What to do

- Use the team TDD chain unless Mihkel chose another mode before writing.
- Name the owner of each task.
- After the plan, ask only "ready to dispatch Task 1 to <owner>?".

## What not to do

Do not offer the skill's end-of-plan execution-mode choice.
