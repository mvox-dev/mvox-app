# Waiting for a live authorization

**When:** you reported a clean dry run and no "I authorize this run" from the team-lead has arrived.

## Why

Only the team-lead's explicit message opens the gate. A clean dry run, a GREEN review or an
earlier go-ahead for another script is not it; a live run once nulled the PO's name in a way
review had missed.

## What to do

- After 15 minutes past the expected authorization, send the team-lead a status ping.
- Read the dispatch wording; some chains need a further PO nod past the team-lead.

## What not to do

Never self-authorize or run live on a guess.
